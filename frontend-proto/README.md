# Pensieve dashboard (frontend-proto)

A static, Harry Potter-themed dashboard for Pensieve memories. No build step, no framework, no transpilation. The Pensieve backend serves it (inside the desktop app, or at `http://localhost:8765/` when you run `pensieve serve` by hand), and the page always talks to the origin that served it.

```
frontend-proto/
|-- index.html      Markup: masthead, page sections, modal scaffolding
|-- theme-init.js   Applies the saved theme before first paint (a file, not inline, for the CSP)
|-- fonts.css       The bundled Cinzel and IM Fell English faces (assets/fonts/)
|-- pensieve.css    Theme tokens (day / night / marauder), House palette, components
|-- pensieve.js     State, rendering, drag and drop, API client, every page and modal
|-- legal.html/.js  About & legal: privacy and AI notice, license, third-party notices
|-- favicon.ico     Generated by desktop/Make-Icon.ps1
|-- assets/         Rendered art: painted backgrounds (parchment, night, map), the
|                   Pensieve emblem, Hedwig, the Snitch, and the fonts. splash-loop.mp4 and
|                   splash-poster.webp are the desktop launcher's splash, not the page's.
|-- README.md       You are here
```

## Masthead

The top row holds the emblem and title, then the status cluster and the sun/moon theme toggle:

- **Hedwig** carries a wax seal with the number of memories that need review (low confidence or flagged by the AI) and bobs while there are any. Click her, or press Enter, to show only those cards.
- **Health** is the Garden board-health score. Hover for the breakdown; click to show only stale, ghost, or overdue cards.
- **Trophy** shows unlocked/total achievements and opens the badge grid. A new unlock fires confetti once.

The controls ribbon below it:

- **Search**: typing filters loaded cards by title, why, and impact. Enter or the magnifier runs a semantic search (`/api/search`, top 20).
- **Lifecycle / Houses** switches the board view.
- **Filter** holds the strand pills, **This week** (hide Closed cards from before this Monday; nothing is deleted), and **Clear filters**. Its badge counts active filters.
- **From your agents** appears only when agents have asked Pensieve to add tasks.
- **Speak a task** and **Pull from To-Do** (sends Hedwig to sync the source chosen on the Accounts screen; she is "flying" while it runs).
- **More**: Refresh, Set goals, AI models, Accounts, the Compact / Comfortable density toggle, and About & legal (also linked from the footer).

**Today's quests** appear under the ribbon when the Garden has quests; click one to filter the board to its cards. The status cluster, ribbon, and quests show on the Board page only.

## Pages

| Page | What it does |
| ---- | ------------ |
| Board | The kanban board (Lifecycle or Houses view) |
| Recap | Drafts a Connect "Reflect on the past" recap per goal, with per-section revise, copy, history, and DOCX export |

## The board

**Lifecycle view** (default): Memory (backlog), Dive (active), Review (needs another look), Closed (done; tasks completed at the source move here on the next sync). Drag a card between columns to move it (`PATCH /api/memories/{id}/column`); dropping it back where it started does nothing.

**Houses view**: one column per Connect goal in its House color, an Unhoused column for work not tied to a goal, and an "Add a House" tile that opens the goals editor. Dropping a card on a House makes it the card's primary House and drops the House it came from; dropping on Unhoused clears every alignment (`PATCH /api/memories/{id}`).

Each goal carries a neutral `lane` slug; the dashboard maps slugs to Houses for presentation only (`LANE_HOUSE` in `pensieve.js`, `--house-*` tokens in `pensieve.css`):

| Lane slug | House | Glyph |
| --------- | ----- | ----- |
| crimson | Gryffindor | lightning |
| gold | Hufflepuff | flower |
| emerald | Slytherin | fleur-de-lis |
| azure | Ravenclaw | atom |
| slate | Internal | alembic |
| ember | Muggleborn | quill |
| sage | Centaur | shamrock |
| rose | Phoenix | blossom |

Goals beyond eight cycle through the palette.

**Cards** show the display title, the strand (inked by kind), a due pill (loud when overdue), the one-line why (Comfortable density only), House chips, a wax-seal "R" when review is needed, a Garden freshness dot, and on closed cards a Vial "Capture" prompt or a captured-count badge. Tab to a card and press Enter or Space to open it; focus returns to the card on close.

## Modals

- **Card**: edit the display title, strand, column, due date, review flag, why, impact, Connect alignment, and a private note. **Regenerate with AI** re-runs enrichment for that card.
- **Vial**: one sentence on what changed when a card closed (Save or Skip). Vials outlive the source task.
- **Goals (Houses) editor**: hand-edit, add, or remove goals, or upload a Connect PDF and let the AI propose them. Edits apply only on Save (`POST /api/goals`, with a localStorage fallback when the API is down).
- **Speak a task**: the browser's speech recognizer (or typing) feeds `/api/capture/parse`, which drafts a confirm card. Nothing is created until you click Add (`/api/capture/add`).
- **From your agents**: task requests other agents filed through the vault bridge. Review and add opens the same confirm card; Dismiss tells the agent no. Either way the answer is written back to the agent's note.
- **Accounts**: opens on first run. Device-code sign-in for Microsoft To Do and GitHub Copilot, plus which source to read tasks from.
- **AI models**: pick the GitHub Copilot model for each job, or test one with a tiny prompt.
- **Achievements**: the badge grid; locked badges show their trigger on hover.

Escape closes any modal or open popover.

## Themes and easter eggs

| Theme | How to switch |
| ----- | ------------- |
| Day (parchment and ink) | Default; the sun/moon button |
| Night (candle-lit navy, starfield) | The sun/moon button |
| Marauder's Map | Type `i solemnly swear that i am up to no good` anywhere outside a text field. `mischief managed` (or the sun/moon button) folds it away. Hedwig hides and the map's "MM" takes her place. |

The choice is saved in `localStorage` (`pensieve-theme`) and applied before first paint, so night and Marauder never flash parchment. Every color, including the Constellation canvas and the confetti, comes from theme tokens. The golden Snitch flits across now and then (one 28-second pass, then a 15 to 45 second rest; hidden in Marauder mode).

## Talking to the API

`API_BASE` is always the page's own origin. When the desktop launcher starts the backend with a session token, the API only answers the app's own window (through a session cookie set on first load); a hand-run `pensieve serve` stays open for development.

On load the dashboard requests `/api/healthz`, `/api/memories`, and `/api/goals` in parallel (plus `/api/strands`, the strand catalog, until it has one) and shows empty column shells until they answer. The Garden (`/api/board/health`, `/api/quests`, `/api/achievements`) loads in the background. If the backend is unreachable, the board stays empty, the footer says "offline", and a toast explains how to recover.

Every 30 seconds the board re-reads memories and goals. The poll stands down while a modal is open, a card is mid-drag, a write is in flight, the tab is hidden, or another page is showing. An unchanged snapshot does nothing; a changed one replaces only the cards whose content changed, so scroll, focus, and open menus survive. A refresh that started before a local change is discarded rather than reverting it. Agent requests are checked every two minutes.

All requests go through one small client (`apiFetch`, `fetchJson`, `sendJson` in `pensieve.js`), which surfaces the server's `detail` message on failure.

## Accessibility and performance

- Text tokens are tuned for WCAG AA on parchment, navy, and the map; keyboard focus gets a candle-gold ring.
- `prefers-reduced-motion` turns off the candle flicker, ink-in, Snitch, footprints, theme crossfade, and other animation.
- The parchment is a fixed composited layer, so scrolling never repaints it. Theme switches crossfade with the View Transitions API where supported.
- The Snitch only animates in flight, the starfield twinkles only at night, and the Constellation stops simulating once calm and caches its palette.
- Search typing is coalesced (80ms); semantic search, graph, and doc requests abort the previous one when superseded.

Tested in current Edge and Chrome on Windows. Uses ES2020, HTML drag and drop, and CSS `color-mix()`, `:has()`, and `:is()`; no polyfills.

## When to edit which file

| You want to | Edit |
| ----------- | ---- |
| Change colors, fonts, theme palettes, House accents | `pensieve.css` (section 1, tokens) |
| Rename a House or change its glyph | `pensieve.js` (`LANE_HOUSE`) |
| Change the Lifecycle columns | `pensieve.js` (`LIFECYCLE_COLUMNS`) |
| Change the strands | `strand_catalog` in `samples.json` in the data folder (served at `/api/strands`) |
| Change how a card renders | `pensieve.js` `cardParts` (markup) and `buildCard` (element) |
| Change how the dashboard talks to the API | `pensieve.js` section 6 (client helpers, Garden, auto-refresh, writes) |
| Add a control | `index.html` (markup) plus a handler in `init()` in `pensieve.js` |

## Constraints

- No build step, no framework, no JavaScript from a CDN.
- Its two typefaces (Cinzel and IM Fell English, SIL OFL 1.1) are bundled in `assets/fonts/` via `fonts.css`, so the dashboard works offline and contacts no font service; size-adjusted local Georgia faces stand in until they load.
- No inline scripts: a Content-Security-Policy from the backend allows only the app's own script files (`theme-init.js`, `pensieve.js`, `legal.js`).
- The page talks only to the local Pensieve API, never to Microsoft, GitHub, or any other service directly. Adding tasks and any writeback to your task source happen in the backend.
