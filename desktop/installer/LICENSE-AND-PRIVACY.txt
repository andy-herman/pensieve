1. WHAT PENSIEVE IS
-------------------------------------------------------------------------------
Pensieve is a free, unofficial personal project that adds a "memory layer" to
your Microsoft To Do tasks: it copies your tasks to this PC, uses AI to note
why each one matters and which of your goals it serves, and shows them on a
board. It runs on your PC. There is no Pensieve account and no Pensieve server.

-------------------------------------------------------------------------------
2. PRIVACY: WHAT STAYS ON THIS PC
-------------------------------------------------------------------------------
Stored in %LOCALAPPDATA%\Pensieve on this PC, for your Windows user only:
- copies of your tasks and the AI-written notes about them;
- your goals, settings and model choices;
- your Microsoft sign-in, encrypted with Windows data protection so only
  your Windows user can read it (your GitHub sign-in is kept by the GitHub
  Copilot CLI in Windows Credential Manager);
- logs, which can include task titles when something goes wrong.
Pensieve collects no analytics or usage telemetry and sends nothing to its
author. Uninstalling offers to delete all of this.

-------------------------------------------------------------------------------
3. PRIVACY: WHAT LEAVES THIS PC, AND ONLY WHEN YOU USE IT
-------------------------------------------------------------------------------
- Microsoft (Microsoft Graph): after you sign in, Pensieve reads your To Do
  lists and tasks, and adds a task only when you confirm one. Governed by
  your Microsoft account terms and the Microsoft Privacy Statement.
- GitHub Copilot: task titles, notes, list names and your goals are sent to
  GitHub Copilot to write the summaries, drafts and recaps. This uses your own
  Copilot plan and is governed by GitHub's terms and privacy statement for
  that plan (Copilot may route requests to model providers GitHub works
  with). Pensieve runs each request with all tools disabled and deletes its
  Copilot session afterwards; GitHub's own retention rules still apply.
- Speech: when you use "Speak a task", your voice is processed by the speech
  recognition service built into Microsoft Edge.
- Setup: the installer can install the GitHub Copilot CLI from GitHub using
  Windows Package Manager (winget).
- Optional: if you turn on the vault bridge, Pensieve writes a summary of your
  board into a folder you choose; any sync service you use copies it.

-------------------------------------------------------------------------------
4. AI NOTICE
-------------------------------------------------------------------------------
AI-written summaries, goal matches, task drafts and recaps can be wrong or
incomplete. Review them before relying on them. They are not professional,
legal, financial, medical or career advice. You are responsible for any task
you add and anything you send based on Pensieve's output.

-------------------------------------------------------------------------------
5. YOUR RESPONSIBILITIES
-------------------------------------------------------------------------------
Connect only accounts you own or are allowed to use. If you connect a work or
school account, or put work information into Pensieve, follow your employer's
or school's policies on AI tools and data. Keep Windows and your accounts
secured; anyone who can sign in as your Windows user can open Pensieve.
